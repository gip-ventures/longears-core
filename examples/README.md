# Examples

| File | Place it at |
|---|---|
| `longears.yml` | `.github/longears.yml` |
| `dependency-scan.yml` | `.github/workflows/dependency-scan.yml` |

`longears.yml` defines which ecosystems to scan and on what schedule.
`dependency-scan.yml` is the workflow that runs the Longears action hourly and uploads the results as an artifact.
